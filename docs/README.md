# openbadgeslib documentation

The project documentation lives in two places:

- **User & developer guide** — the
  [GitHub Wiki](https://github.com/luisgf/openbadgeslib/wiki): installation,
  configuration, concepts, the security model, CLI reference, how-to guides,
  contributing and releasing.
- **API reference** — generated from the docstrings with
  [pdoc](https://pdoc.dev) and published at
  <https://luisgf.github.io/openbadgeslib/>.

The legacy Sphinx site that used to live in this directory was retired in favour
of the Wiki + the generated API site (it had drifted from the code and the build
was broken). `authors.rst` and `glossary.rst` are kept here for reference; the
same content is in the Wiki
([Authors / License / FAQ](https://github.com/luisgf/openbadgeslib/wiki/Authors-License-and-FAQ)
and [Glossary](https://github.com/luisgf/openbadgeslib/wiki/Glossary)).
